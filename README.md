# Super Rabbit Boy

Open `super-rabbit-boy.html` in a web browser to play.

## Controls

- **Left / Right** — travel through the level
- **Forward / Back** or **W / S** — move between the front and back lanes
- **Jump** or **Up Arrow** — jump onto enemies and platforms
- **Dash** or **X** — move quickly forward
- **Attack** or **Z** — strike robots from the side

## Objective

Defeat King Viking with three jump attacks, then clear every robot. The rainbow flag opens once the level is safe.

## Files

- `super-rabbit-boy.html` contains the complete game: artwork, game logic, controls, and level data.
